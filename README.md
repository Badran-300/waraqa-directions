# ورقة — استكشاف الشخصية

[افتح العرض](https://badran-300.github.io/waraqa-directions/)

٤٠ اتجاهًا لشخصية ورقة، و٣٠ شخصية جديدة لبوابة الموظفين. لكل اتجاه شريحة مستقلة، مع ألوان مقترحة وأمثلة للاستخدام. العرض بالعربي، ويتيح حفظ المفضلة والمقارنة وتحميل نسختي PDF وPowerPoint.

هذه تصوّرات أولية. الحركة مقترحة وليست تحريكًا نهائيًا. بطاقات البوابة أمثلة توضيحية دون بيانات موظفين.

النشر يمر بطلب دمج واختبار إلزامي، ثم تشغيل مستقل لمسار النشر.
