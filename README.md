# ورقة — استكشاف الشخصية

٤٠ اتجاهًا لشخصية ورقة، و٣٠ شخصية جديدة لبوابة الموظفين. لكل اتجاه شريحة مستقلة، مع ألوان مقترحة وأمثلة للاستخدام. التنقّل بالسابق والتالي أو فهرس الشرائح.

هذه تصوّرات أولية. الحركة مقترحة وليست تحريكًا نهائيًا. بطاقات البوابة أمثلة توضيحية دون بيانات موظفين.

النشر على Vercel يمر بطلب دمج واختبار إلزامي، ثم تشغيل مستقل لمسار النشر. ملفات PDF وPowerPoint محفوظة ضمن المصدر، ولا تدخل في نسخة العرض المنشورة على Vercel.
